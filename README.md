# dot_news_bot

Telegram-бот для канала DOT NEWS. Он читает RSS-источники, проверяет дубликаты в SQLite, делает короткий пост на русском через OpenAI, ищет `og:image`, отправляет черновик админу и публикует в канал только после подтверждения.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:

- `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
- `TELEGRAM_ADMIN_ID` — числовой Telegram ID администратора.
- `TELEGRAM_CHANNEL_ID` — username канала, например `@dot_news_channel`, или ID.
- `OPENAI_API_KEY` — ключ OpenAI API.

Бота нужно добавить в канал администратором с правом публикации сообщений.

## Запуск

```bash
python app.py
```

После запуска веб-панель доступна по адресу `http://127.0.0.1:8080`. Она запускается в отдельном потоке вместе с Telegram-ботом и не требует отдельного процесса.

Если Telegram-бот ещё не настроен, панель можно запустить отдельно:

```bash
python web_app.py
```

Параметры панели в `.env`:

- `WEB_ENABLED=true` — включить или выключить панель.
- `WEB_HOST=0.0.0.0` — bind для доступа из локальной сети; панель не публикуется в интернет.
- `WEB_PORT=8080` — порт панели.
- `AUTO_SCAN_ENABLED=false` — начальное значение автосбора; текущее состояние хранится в SQLite.
- `SCAN_INTERVAL_MINUTES=5` — интервал автоматического поиска после завершения предыдущего цикла.
- `PUBLICATION_INTERVAL_MINUTES=5` — пауза между несколькими автоматическими публикациями одного цикла; значение можно изменить в разделе «Настройки» без перезапуска.
- `SCAN_LIMIT_TOTAL=50` — максимум новых материалов за один скан.
- `MAX_TELEGRAM_AUTO_PER_SCAN=2` — максимум двух сильных Telegram-постов за цикл.
- `MAX_TELEGRAM_AUTO_PER_HOUR=12` — общий часовой лимит автоматических Telegram-публикаций.
- `MAX_NEWS_AGE_HOURS=72` — максимальный возраст новости для нового черновика.

## Команды

- `/start` — проверка запуска.
- `/panel` — открыть панель управления с кнопками.
- `/scan` — прочитать RSS и отправить новые черновики админу.
- `/drafts` — показать последние черновики.
- `/status` — статистика по статусам в SQLite.
- `/sources` — список RSS-источников.
- `/refreshmedia` — повторно найти фото для существующих черновиков.
- `/search Варшава` — найти свежие новости по произвольной теме.

После `/start` бот показывает постоянное меню с кнопками для основных действий. В верхнем меню Telegram также доступны основные команды.
- `/addsource Название | RSS-ссылка | категория` — добавить RSS-источник.

Автосбор и автопостинг управляются независимыми переключателями в SQLite. Автоскан запускается сразу после старта и повторяется через `SCAN_INTERVAL_MINUTES` после завершения цикла. Telegram-автопостинг работает только при `RANKING_DRY_RUN=false` и score от `IMPORTANCE_AUTO_PUBLISH` (текущий рабочий порог 60). За цикл публикуются максимум два лучших кандидата, а за час — максимум 12. Новости с самым высоким score идут первыми; остальные остаются в очереди.

TikTok-автопостинг включается отдельно через `TIKTOK_AUTO_PUBLISH_ENABLED` или веб-панель и требует score от `TIKTOK_AUTO_PUBLISH_SCORE` (текущий рабочий порог 62). Он запускается только после успешной Telegram-публикации, использует реальное фото, проверенный GitHub Pages URL, русский AI-текст и доступный privacy level. Для DIRECT PHOTO включён `auto_add_music`: TikTok сам добавляет рекомендованную музыку. Fallback-фото для реальных новостей не используется. Ошибка TikTok записывается отдельно и не отменяет публикацию в Telegram. Повторные попытки TikTok ограничены тремя попытками с задержками 2, 5 и 10 секунд.

В веб-панели доступны действия «Найти новости», поиск по произвольной теме, «Проверить фото», «Обновить список» и «Опубликовать» или «Пропустить» для каждого черновика. Раздел «Настройки» позволяет изменить интервал сканирования RSS и паузу между автоматическими публикациями; значения сохраняются в таблице `settings` SQLite. Страница обновляется раз в 60 секунд и сохраняет текущий раздел, фильтр и поисковый запрос.

В блоке `Automation` отображаются оба переключателя, пороги, состояние `RANKING_DRY_RUN` и последние 10 автоматических решений. Состояния TikTok разделяются на `NOT_ELIGIBLE`, `SKIPPED_NO_IMAGE`, `PROCESSING`, `PUBLISHED` и `FAILED`. Кнопки «Очередь публикации» и «Автоматизация» открывают отдельные представления панели.

В очереди публикации показывается назначение каждой новости: Telegram, TikTok или обе площадки. Кнопка «Удалить» убирает новость из очереди безопасно: запись сохраняется в SQLite со статусом `skipped` и повторно не выбирается для автопубликации.

На рабочем столе доступны ярлыки `DOT News - START` и `DOT News - STOP`. Они запускают и останавливают `app.py` этого проекта; состояние запуска хранится в локальном `.dot_news_app.pid`.

## TikTok Sandbox OAuth

В панели есть кнопка `Connect TikTok`. Она запускает тестовую OAuth-авторизацию с PKCE и scopes `user.info.basic,video.publish` через зарегистрированный callback `http://127.0.0.1:8080/auth/tiktok/callback`.

Sandbox credentials задаются только в `.env` через `TIKTOK_CLIENT_KEY` и `TIKTOK_CLIENT_SECRET`. После успешного обмена токены сохраняются локально в `.tiktok_tokens.json`, который не обслуживается веб-панелью и добавлен в `.gitignore`. В панели доступен только ручной тестовый PHOTO-пост: перед отправкой выбирается доступный privacy level, после init запрашивается статус публикации. Автопубликация новостей в TikTok не реализована и не включается.

## Кнопки под черновиком

- `✅ Опубликовать` — публикует пост в канал и сохраняет статус `published`.
- `🔁 Переписать` — просит OpenAI сделать новый вариант и отправляет его админу.
- `🖼 Без фото` — убирает картинку из черновика.
- `❌ Пропустить` — сохраняет статус `skipped`.

Кнопка ручной публикации новости из списка отправляет её только в Telegram. TikTok публикуется отдельным ручным потоком через «Publish to TikTok», preview и подтверждение privacy level; ручная Telegram-публикация автоматически не дублируется в TikTok.

## Источники

RSS задаются в `sources.json`:

Текущая подборка включает 17 RSS-источников с приоритетом Польши и Украины: PAP (все категории и политика), Notes from Poland, Onet, Interia, Украинская правда, Google News по Украине и украинцам в Польше, польские безопасность и экономика. Для главных мировых тем подключены TVN24, BBC World, The Guardian, Politico EU и Google News World; отдельно остаётся лента технологий и ИИ.

В каждом скане материалы выбираются по кругу между источниками, поэтому мировой и украинский блоки не вытесняются польскими лентами из-за общего лимита. Обсуждаемость сейчас оценивается через повторяемость события в нескольких источниках и существующую формулу `importance_score`; отдельный мониторинг соцсетей пока не подключён.

```json
[
  {
    "name": "Польша: политика",
    "url": "https://news.google.com/rss/search?q=Polska%20polityka&hl=pl&gl=PL&ceid=PL:pl",
    "category": "политика"
  }
]
```

## База данных

SQLite создается автоматически. Таблица `articles` содержит:

- `id`
- `source_name`
- `original_url`
- `original_title`
- `rewritten_post`
- `image_url`
- `status`
- `created_at`
- `published_at`

Если OpenAI API недоступен, бот отправит админу сообщение об ошибке и продолжит работу. Если изображение не найдено, черновик все равно создается без изображения.
